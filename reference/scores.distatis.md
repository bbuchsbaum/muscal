# Scores from a DISTATIS Model

Scores from a DISTATIS Model

## Usage

``` r
# S3 method for class 'distatis'
scores(x, ...)

# S3 method for class 'distatis'
sdev(x)
```

## Arguments

- x:

  A fitted `distatis` model.

- ...:

  Unused arguments.

## Value

The object-by-component compromise scores.

[`sdev()`](https://bbuchsbaum.github.io/multivarious/reference/sdev.html)
returns square roots of the retained object eigenvalues.
